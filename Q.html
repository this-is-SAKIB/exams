I. Tangent Lines

Write the equation of the tangent line to the graph of the function at the point $x = 0$ for:

  1. $f(x) = \sqrt{1 + \cos^2 x}$
  2. $f(x) = \sqrt{1 + \sin 2x}$
  3. $f(x) = \log(1 + \cos 2x)$
  4. $f(x) = \sin^2 (\frac{\pi}{4} + 5x)$
  5. $f(x) = \cos^2 (\frac{\pi}{4} + 2x)$

II. Formal Definitions

  1. State what it means that $\lim_{x \to 1} f(x) = 5$ for a function $f : \mathbb{R} \to \mathbb{R}$ using the formal definition.
  2. Define what it means for $f$ to be derivable at the point $x_0 = 0$ for a function $f : \mathbb{R} \to \mathbb{R}$.
  3. Let $f : \mathbb{R} \to \mathbb{R}$. Using the definition, say what it means that $\lim_{x \to -1} f(x) = 3$.
  4. Let $f : \mathbb{R} \to \mathbb{R}$. Using the definition, say what it means that $\lim_{x \to 2} f(x) = -1$.
